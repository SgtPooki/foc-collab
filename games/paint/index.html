paint war, event-sourced

One 64 by 64 canvas. Every pixel is a signed piece in the arcade's paint data set on Filecoin Onchain Cloud, written by a key your browser mints; a contract lets each painter place one pixel every couple of minutes from a daily budget the arcade funds. Highest piece id wins a cell. No wallet, no server. A pixel takes about a minute to settle; yours shows at once.
